GREEN / 绿色 — Interactive Photography Website

HOW TO USE
1. Unzip this folder.
2. Open index.html in Chrome / Edge.
3. Move your mouse over the photos, choose a feeling, sample a green, and leave a memory.

WHAT IS INCLUDED
- index.html
- style.css
- script.js
- images/green_1.jpg ... green_7.jpg

NOTE
The "TALK" section saves visitor responses only in the browser's localStorage. It is intentionally a local prototype, not a public database.
All seven photographs in this prototype are the user's own uploaded photographs.
